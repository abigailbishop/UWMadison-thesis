\chapter{Analysis of the Second Station for the Askaryan Radio Array's Five Station Analysis}

  After reducing our 10\% data to a predominantly thermal-like collection of events, we are ready to construct an analysis that separates potential signal from our thermal-like background. 
  This is done by training a Linear Discriminant Analysis algorithm on each station-configuration, which transforms 19 variables into one number that is low for background events and high for simulated neutrino events. 
  The distribution of LDA values for thermal-like events is fitted and passed, along with the model of surface-like events identified in Section~\ref{sec:zc_slc}, to an optimization algorithm that identifies the best LDA cut for each station-configuration in the context of each arraywide configuration and the best zenith cut for the 6 instruments. 
  Once the LDA cut (discriminating signal from background) and the zenith cut (rejecting cosmic rays and unparameterized anthropogenic noise) are optimized, the analysis is applied to the 100\% dataset. 
  Any events that survive all analysis cuts (cleaning, zenith, and LDA) are then passed through an isolation condition that removes any events that occurred within 5 seconds to 5.8 hours of each other, as we don't expect to find multiple neutrino events in close succession, except for muon and tau tracks of stochastic losses and a tau decay. 
  We outline a plan for how to assess any remaining passing events, in case they are due to unforseen backgrounds not present in the 100\% sample. 
  Lastly we use the expected background rates and number of passing events to establish an upper limit on the flux of UHE neutrinos. 

\section{Linear Discriminant Analysis}

  In this analysis, the ultimate signal and background discrimination is performed using a Linear Discriminant Analysis (LDA).
  Previous analyses have used the Fisher Discriminant or a cut in the 2 dimensional distribution of event correlation against signal strength. 
  An LDA is a generalization of Fisher Discriminants and, if only using two variables, performs similarly to separating signal and background by drawing a line in the 2 dimensional histogram of event correlation versus signal strength. 
  LDAs, for each event, will take a collection of analysis variables and combine them linearly into a single number by multiplying the array of variables for each event against a matrix that's been optimized for signal-background separation using a training set. 
  The transformation matrix additionally will downweight variables such that multiple, highly correlated observational metrics are not overrepresented. 
  This analysis uses 19 variables summarized in Table~\ref{tab:LDAvars}, a signal dataset composed of simulated neutrino events following an $E^{-2}$ spectrum, and a background dataset composed of all events from each station's cleaned 10\% burn sample.

\section{Optimization}

  After the LDA transformation matrices are set, we feed the thermal background LDA model and the surface event elevation models for each station-configuration into an algorithm that determines the best LDA cut and Zenith cut for each array wide configuration. 
  As there are 50 array wide configurations comprised of 140 instances of our stations and 6 instruments to set zenith cuts for, this algorithm is optimizing a 146-dimension puzzle. 
  The optimized A2 zenith cut is $10.31^{\circ}$ in elevation and LDA cuts are in Table~\ref{tab:ldacuts}. Note that as the LDA transformation matrix is optimized separately for each station-configuration, the resulting LDA scores for each station-configuration should not be compared to each other. Said another way, if one station-configuration has an LDA cut of 1.2 and another has a cut at 1.4, this does not simply imply the former is better than the latter.

  \subsection{Isolation Condition}

    As neutrinos are expected to be rare, it is even rarer that neutrinos would occur in a narrow time window. 
    To avoid clusters of temporally clustered, neutrino-like background events from passing this analysis, we enforce an Isolation Cut to remove events that pass all cuts but exist within a short time window. 
    This time window was determined via a toy Monte Carlo simulation which sampled a number of neutrino events from a Poisson distribution with a mean of 15 and randomly distributed these events over the 10.6 year livetime covered by this analysis. 
    The time between consecutive events was calculated for all trials, plotted in Figure~\ref{fig:isolation_condition}, and used to determine the time window that had less than 0.001\% probability of removing neutrinos from our sample. 
    This resulted in a time window of 5.8 hours. 

    \begin{figure}
        \centering

    However, this analysis considers neutrino events that may involve multiple cascades resulting from muon stochastic losses, tau stochastic losses, and tau decays. 
    We expect that these types of events will not trigger the same detector twice very often, given the lengthy ($\mathcal{O}(\text{1 ms})$ deadtime of ARA stations) and need to observe cascades close to the cone of radiation, but in Figure~\ref{fig:multistation} we showed that we expect multiple stations to observe one or more cascades resulting from $10^{19}$~eV neutrinos 10\% of the time, increasing to 35\% for neutrinos with $10^{21}$~eV of energy.
    To prevent the removal of these multi-station events, we retain passing event multiplets within a time window of 5~s.

    \subsection{Results}

      The results of the analysis on the 100\% revealed just a single passing event taken by the PA. 
      As only one event was found, no events were cut by the time isolation cut. 
      Some analysis variables of the PA event are presented in Table~\ref{tab:paevent} but the full suite is provided in Appendix~\ref{app:passingevent}. 
      This event saturated the PA DAQ when it was recorded, had an SNR of 12.(x) in the VPols and 11.(x) in the HPols. 
      Both the reconstruction algorithm and visual analysis of the event strongly suggest an up-traveling signal originating in the ice.
